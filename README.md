# Customer Churn Prediction & Business Analytics

## Project Overview

Customer Churn Prediction is a machine learning project that predicts whether a customer is likely to leave a company.

The project uses customer information such as age, monthly charges, tenure, and contract type to make predictions.

## Objectives

- Predict customer churn
- Identify important customer characteristics
- Analyze customer churn data
- Provide a simple business analytics dashboard
- Help businesses identify customers who may leave

## Dataset

The dataset contains 1000 customer records.

Features used:

- Age
- MonthlyCharges
- Tenure
- Contract

Target variable:

- Churn

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Logistic Regression

## Machine Learning Model

Logistic Regression is used for predicting customer churn.

## Application Features

- Customer input form
- Churn prediction
- Churn distribution
- Contract distribution
- Churn rate
- Average monthly charges
- Average customer tenure
- Customer data table

## How to Run

Install the required libraries:

pip install pandas scikit-learn streamlit

Run the application:

streamlit run app.py

The application will open in the browser.

## Result

The application predicts whether a customer may churn or is likely to stay.
